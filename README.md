# Bhavan Kumar Portfolio

A modern and interactive personal portfolio website.

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Design

## Features

- Dark/Light Mode
- Bento Grid
- Glassmorphism
- Animated Background
- Interactive Cards
- Project Filtering
- Portfolio Chatbot
- Scroll Animations
- Progress Indicators
- Responsive Design

## Installation

1. Download the project.
2. Open the folder in VS Code.
3. Add your images to `assets/images`.
4. Add your resume to `assets/resume`.
5. Open `index.html` in your browser.
